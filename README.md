# OnboardMate

A simple onboarding dashboard to help interns, fresh graduates, and new employees prepare for their first days at work.

## Features

- Onboarding checklist for the first day and first week
- Progress tracking
- Role selection
- Onboarding Buddy chat demo
- Suggested questions to ask mentors or HR

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

Clone the repository and open `index.html` in your browser.
